# гайд сборки ядра

`build32.sh` скрипт компиляции

для компиляции elf программ используем файл линковки ld/elf.ld

для компиляции raw модулей(.mod) `build_module путь.c ramdisk/имя.mod` 

`init.h` настройки инициализации ОС

# гайд на консоль

базовый формат команды `name [args]`

вызов функции по адресу `*0xaddr [args]`

## правила передачи аргументов:
- строковые аргументы передаются без префикса. пример `_printf hack`
- числа передаются с префиксом i:число. пример `_dmp i:0x1000 i:64`
- одиночные символы !БУКВЫ ДИСКОВ! передаются с префиксом c:. пример `_elfload c:A ./hello.elf`

# типы функций
1. fastcall - обычные строготипизированные функции, как в C
2. zhirfunction - функции, которые принимают переменное число аргументов и автоматически определяют их тип. используются для безопасности и защиты от typeconfusion в zhirvm
